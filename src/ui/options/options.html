🦾 Javis Settings

Javis is model-agnostic. Point it at any OpenAI-compatible endpoint — local Ollama (free, private) or a cloud key. Replaying learned skills uses no model at all; the model is only called while learning or self-healing.

The page-agent demo endpoint (qwen3.5-plus, no key) is for evaluation only and routes through third-party servers — do not use it for real data or a published product.
