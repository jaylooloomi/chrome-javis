🦾 Javis Settings

Model (for learning skills)

Any OpenAI-compatible endpoint — local Ollama or a cloud key. Replaying a learned skill uses no model.

The page-agent demo endpoint (qwen3.5-plus, no key) is evaluation-only and routes through third-party servers — not for real data.

Form-fill model

Filling forms is a small task — Chrome's on-device Gemini Nano is private, free and offline. Falls back to your endpoint if Nano isn't ready.

Nano: checking…

On-device Nano needs Chrome with built-in AI and a one-time model download (~22 GB disk). If unavailable, Auto silently uses your endpoint.

Your profile (for form-fill)

Stored encrypted on this device only. Javis maps these to a form's fields when you fill it. Leave blanks empty.
